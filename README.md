# 🚀 HetIsRoan Studio's - Officiële Website

Welkom bij de broncode van **HetIsRoan Studio's**! Een strakke, moderne en responsieve website ontworpen voor het aanvragen van op maat gemaakte websites, het beheren van sollicitaties en het live publiceren van portfolio-projecten via Supabase.

## ✨ Features

* 🎨 **Modern & Strak Design:** Volledig op maat gemaakt zonder overbodige ballast.
* 🌓 **Dark & Light Mode:** Eenvoudig schakelen tussen donker en licht thema.
* 📱 **Volledig Responsief:** Werkt optimaal op zowel desktop als mobiel.
* ☁️ **Supabase Cloud Synchronization:** Live instellingen, aanvragen en sollicitaties gesynchroniseerd over alle apparaten.
* 🔒 **Beveiligd Admin Dashboard:** Centraal beheer van inzendingen en site zichtbaarheid.
* 💼 **Dynamisch Portfolio:** Zet goedgekeurde projecten met één klik direct live op de portfolio-pagina.
